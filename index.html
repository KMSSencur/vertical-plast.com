Table concepts · animated

One clamp. Five ways to feed it.

The vertical clamp closes, the injection unit drops onto the mould, injects and lifts away. What happens next depends on the table: it waits for the operator, slides out towards them, shuttles a second mould in, or turns so loading and moulding run in parallel.

Type 1 · standard table

Standard table

One lower mould on a fixed table. The operator unloads the part and places the next insert between the tie bars while the machine waits.

  1. Clamp closes
  2. Injection unit moves down
  3. Injection
  4. Holding pressure & cooling
  5. Injection unit moves up
  6. Clamp opens
  7. Operator unloads & loads insert

Type 2 · single slide

Single slide table

One lower mould on a table that slides out of the clamp towards the operator. Loading happens outside the clamp area, safe and with a clear view.

  1. Clamp closes
  2. Injection unit moves down
  3. Injection
  4. Holding pressure & cooling
  5. Injection unit moves up
  6. Clamp opens
  7. Table slides out
  8. Operator unloads & loads insert
  9. Table slides in

Type 3 · double slide

Sliding table

Two lower moulds on a shuttle. One is moulded while the operator loads the other, then the table slides across.

  1. Clamp closes
  2. Injection unit moves down
  3. Injection
  4. Holding pressure & cooling
  5. Injection unit moves up
  6. Clamp opens
  7. Table slides to next mould

Type 4 · rotary table, 2 stations

Rotary table

Two stations on a turntable. Moulding runs at the back, loading at the front, and the table turns 180° each cycle.

  1. Clamp closes
  2. Injection unit moves down
  3. Injection
  4. Holding pressure & cooling
  5. Injection unit moves up
  6. Clamp opens
  7. Table rotates 180°

Type 5 · rotary table, 3 stations

Multi-station rotary

Three stations indexing 120°. One is moulded, one keeps cooling after injection and one is unloaded and loaded by the operator, for long cooling times or insert-heavy parts.

  1. Clamp closes
  2. Injection unit moves down
  3. Injection
  4. Holding pressure & cooling
  5. Injection unit moves up
  6. Clamp opens
  7. Table rotates 120°

Built vertical
for a reason.

Vertical injection moulding holds the insert flat and lets gravity and the clamp do the fixturing. That is why insert moulding, insert overmoulding and metal overmoulding run cleaner on a vertical machine than on a horizontal one — and why the moulded part leaves the cell at a higher added value.

Insert moulding

Metal in, part out, one cycle.

On a vertical rotary table the operator or robot loads the insert while the previous part is moulding. The table indexes, the vertical clamp closes over a stable insert, and metal overmoulding happens without the part shifting. See the full process →

Automation

Feeding

Bowl, tray or magazine feeding places metal inserts into the vertical rotary table, cycle after cycle.

Vision

Camera checks insert presence and orientation before the clamp closes — scrap stays out of the mould.

Take-out

A robot removes the overmoulded part, degates and sets it down oriented for the next step.
